Installing a new shower or bathtub involves more than setting the fixture in place. The rough-in plumbing behind the wall, the drain connection, and the valve all have to be right before any tile or finish work happens.

Why This Comes Up In Altadena

Bathroom remodels are common across Altadena's older housing stock, where original 1950s and 1960s bathrooms often have smaller footprints and dated fixture layouts that homeowners want to update during a renovation.

Eaton Fire rebuild projects need bathroom plumbing built from scratch, which is an opportunity to plan drain and supply line placement for the finished layout rather than working around an existing rough-in.

A tub-to-shower conversion in particular is worth planning around the home's existing subfloor and joist layout, since a curbless pan sometimes needs a build-up transition that a standard tub never required.

When To Consider A New Installation

Outdated Or Damaged Fixture

A cracked tub or a shower pan with water damage underneath is a common reason for full replacement rather than repair.

Bathroom Remodel

A full remodel is the natural time to reconfigure plumbing for a new layout, such as converting a tub to a walk-in shower.

Rebuild Construction

New construction after the Eaton Fire needs bathroom plumbing rough-in built to current code from the start.

Accessibility Needs

Converting a tub to a curbless shower is a common accessibility upgrade that requires re-routing the drain.

How We Approach Installation

For a tub-to-shower conversion, we assess the existing drain location and slab or subfloor condition first, since a curbless shower pan often needs different drain positioning than a standard tub.

Every installation follows California Plumbing Code requirements for valve types, including anti-scald pressure-balancing valves, and proper venting for the new fixture's drain.

Installation Options

Direct Replacement

A new tub or shower installed in the same footprint as the old one, with minimal rough-in changes.

Tub-To-Shower Conversion

Removing a tub for a walk-in shower, which usually requires drain relocation and new pan installation.

New Construction Rough-In

Full plumbing rough-in for a rebuild or addition, planned around the finished bathroom layout.

Fixture Coordination

Valve placement, shower head height, and drain slope are confirmed together before any tile work begins, since moving one after the fact means reopening finished walls.

Common Questions

Can you convert my bathtub to a walk-in shower?

Yes. This typically involves relocating the drain and installing a new shower pan, which we plan around your bathroom's existing layout.

Do you handle plumbing for a full bathroom remodel?

Yes, including rough-in for new fixture locations, not just replacing an existing tub or shower in place.

What valve type is required for a new shower?

California Plumbing Code requires anti-scald pressure-balancing or thermostatic valves for showers, which we install on every new installation.

How long does a shower or tub installation take?

A direct replacement in the same footprint is often finished in a day. A tub-to-shower conversion with drain relocation typically takes longer depending on subfloor access.

Can you match plumbing rough-in to a specific fixture brand I've already chosen?

Yes. We confirm rough-in dimensions and connection types against your chosen fixture's specifications before starting, so the finish installation goes in without surprises.

Is a permit required for a shower or tub replacement?

A direct like-for-like replacement often does not need one, but any drain relocation or layout change typically requires a permit, which we confirm before starting.

Before We Arrive

  • Have your general remodel plan or any contractor drawings available if this is part of a larger renovation.
  • Note whether you are planning a direct replacement or a layout change, such as a tub-to-shower conversion, since that changes the scope significantly.
  • If this is for a rebuild, have your permit or contractor's timeline available so we can coordinate the plumbing rough-in accordingly.
